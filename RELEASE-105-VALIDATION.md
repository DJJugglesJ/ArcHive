# ArcHive 1.0.5 release validation

This release packages searchable tag browsing, tag sorting, favorite tags and games, and reversible tag/game blacklists. See BROWSING-VALIDATION.md for feature and v1.0.4 upgrade evidence.

Release checks use an isolated library. Package results, checksum comparisons and updater availability are recorded in the GitHub release verification attachment. No personal library, credentials or local test data are included in release assets. Packages are unsigned.
